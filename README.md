# Econometrics concept graph

View the interactive graph at https://AaronScherf.github.io/econometrics-concept-graph-site/.

This repository contains the published, standalone viewer. The graph's editable YAML and development history are kept in a separate private repository. The page includes the graph content needed to display and review it; dashed outlines identify items awaiting owner review.

To report a correction, use the page's **Submit review** button or open an issue in this repository. The review issue is public. You can also use **Download review** and send the file to the maintainer privately.
